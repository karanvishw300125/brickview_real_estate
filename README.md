# 🏠 Brickview Real Estate

Brickview Real Estate is an interactive real estate analytics dashboard built using Python, SQL, SQLite and Streamlit.

## 🚀 Features

- Real estate listing analysis
- Property filters and explorer
- Interactive property listing map
- Average property price by city
- Property type distribution
- Monthly sales and listings trends
- CRUD operations
- 30 SQL analytical queries
- Buyer and agent analysis
- Sales performance analysis

## 🛠️ Technologies Used

- Python
- Pandas
- SQLite
- SQL
- Streamlit
- Plotly

## 📊 Dashboard Sections

### 1. Information
Provides an overview of the real estate database including:

- Listings
- Sales
- Buyers
- Agents
- Average Sales Price

### 2. Filters & Explorer

Users can filter properties using:

- City
- Price
- Property Type
- Agent
- Listed From
- Listed To

### 3. Visualization

The dashboard contains:

- Property Listing Map
- Average Price by City
- Property Type Distribution
- Monthly Sales Trend
- Monthly Listings Trend

### 4. CRUD Operations

Users can perform:

- Create
- Read
- Update
- Delete

operations on real estate records.

### 5. SQL Queries

The project contains 30 SQL analytical queries covering:

- Property pricing
- Property characteristics
- Sales analysis
- Agent performance
- Buyer behavior
- Loan analysis
- Sales trends
